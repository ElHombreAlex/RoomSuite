# RoomSuite module icons

These SVGs adapt the supplied RoomSuite icon set. `ink/` is for light backgrounds; `light/` is for dark backgrounds. The common viewBox is 120 × 120, with flame orange accents.

PixelRoom uses a new image-editing mark. CaptureRoom uses the original Pixel viewfinder. Cliproom uses a clapperboard with an editing playhead; NotesRoom uses a notebook with a bookmark; and the RoomSuite arch has been enlarged for small sizes. The other room marks retain the supplied geometry.

PixelRoom and Cliproom can also be served independently, so copies of their ink and light icons live in their own static directories. Keep those copies in sync with these SVGs when changing either mark.
