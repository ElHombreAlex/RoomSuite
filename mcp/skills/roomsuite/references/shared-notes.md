# Shared files and NotesRoom

Tool names below may require `roomsuite_find_tools` → `roomsuite_tool_schema` → `roomsuite_invoke`; the live schemas define exact arguments.

## Shared files and the agent workspace

- The skill does not know what exists on this instance. Find Shared files with `roomsuite_shared_list` or `roomsuite_shared_search`; inspect bounded text or media with `roomsuite_shared_preview`. `roomsuite_shared_search_content` searches supported UTF-8 Shared files, not the separate NotesRoom store. Search notes, saved PaintRoom projects, and Cliproom projects with their own list tools when relevant. Check truncation and skipped counts before concluding nothing exists.
- Find local agent-workspace inputs with `roomsuite_list_files` and inspect media with `roomsuite_media_info`. Copy a local input to Shared files with `roomsuite_shared_upload` (`input` is local, `path` is shared); reverse the direction with `roomsuite_shared_download` (`path` is shared, `output` is local). The target must be new and its parent must already exist. Use `roomsuite_shared_mkdir` for one shared folder at a time and `roomsuite_shared_move` to move or rename without overwriting. In standard mode `roomsuite_shared_mkdir` may need discovery and `roomsuite_invoke`; older servers may report only `Not found.` for a missing destination folder.
- For a large JSON or `.paintroom` input when the host cannot write a file directly, use `roomsuite_write_begin`, ordered `roomsuite_write_append` chunks, and `roomsuite_write_finish`; use `roomsuite_write_abort` to discard a session. The finished file is in the MCP workspace, not Shared files. Repeating an accepted chunk with the same index and bytes is safe. This create-only write session does not lock Shared files or replace revision checks on edits.
- Use `roomsuite_shared_references` to inspect possible saved references before cleanup. `roomsuite_shared_trash_unreferenced` rechecks a sufficiently complete scan with its returned revision and required acknowledgment. Open/unsaved work, unsupported formats and external files remain outside the scan. For an explicitly requested removal, `roomsuite_shared_trash` offers recoverable trash; `roomsuite_trash_list` and `roomsuite_trash_restore` recover it. `roomsuite_shared_delete` and `roomsuite_trash_purge` permanently delete.
- For snapshots, use `roomsuite_shared_history_list`, `roomsuite_shared_snapshot`, `roomsuite_shared_history_download`, and `roomsuite_shared_history_restore`; restore creates a new Shared path. `roomsuite_shared_history_delete` permanently removes a version.

## Notes

- `notesroom_list` searches notes; `notesroom_get` returns Markdown, the note ID, revision, and URL. Use `notesroom_create` to create one, and `notesroom_update` with its latest `base_revision` to edit or move it. `notesroom_folders` lists or creates folders; `notesroom_delete_folder` removes an empty folder. `notesroom_delete` permanently deletes the note.
- `notesroom_link` inserts a stable note-ID link and `notesroom_links` inspects saved links/backlinks. Its scan can omit unsaved notes.
- A protected note-media copy is stored separately from the Shared file, so moving the original does not break the note; identical copies may be reused. For image or audio media already in Shared files, `notesroom_attach_media` creates or reuses the copy and attaches it with the note's current revision; `notesroom_attachment_create` prepares one independently. `notesroom_protect_media` upgrades supported old path-only links. Prepared copies may remain if saving fails. `notesroom_attachment_audit` reports protected copies; `notesroom_attachment_delete` permanently deletes an eligible unreferenced copy only after its required checks.
- `notesroom_export_bundle` writes a `.roomnote` containing a saved note and supported media to the agent workspace; linked notes are not included. `notesroom_import_bundle` creates a new note; reuse its `import_id` for a retry after a lost response.
