# RoomSuite motion showcase benchmark

This is a separate creative benchmark for a RoomSuite product video. The visual reference is a 30-second, 1280 × 720 landscape product demo with a dark dotted background, floating interface panels, warm highlights, a small animated pointer, concise typography and quick transitions between use cases. The reference has an audio track. Attach the reference video to the agent if it can receive it; the description below is a fallback if it cannot access the file.

Start a fresh agent session and record usage across all providers/accounts before and after the complete run. This is a creative brief, not a verified cost or a completed video.

```text
Create a polished RoomSuite motion-design product video, taking visual inspiration from the attached reference if you can access it. The reference is a 30-second landscape product demo: a charcoal dotted-grid background, softly glowing warm accent, floating dark interface cards, a small animated pointer, crisp white sans-serif text, and smooth zooms, slides, fades and highlighted controls. Use the same premium, concise product-demo feel, but create an original RoomSuite story, artwork and compositions; do not copy the other product's name, logo, pricing, text, screenshots or soundtrack. If the reference is inaccessible, use this description and say so.

Tell a clear story about real RoomSuite use cases and benefits. The suite is self-hosted and brings creative rooms, productivity tools and shared files together. An external AI agent can use RoomSuite through its optional MCP integration. Use the RoomSuite name and its actual arch/room icons and flame accent where available; local rasterization of repository SVGs for animation is permitted. Use real interface captures where available or clearly illustrative mockups, and do not imply that an agent chat is built into RoomSuite itself.

STORYBOARD — approximately 30 seconds, landscape 16:9
0–4 s: Introduce RoomSuite and its workspace, with a confident opening animation.
4–9 s: Show an external AI agent using MCP to turn a brief into a project.
9–15 s: Bring creative work to life: a design or poster moves from artwork to MotionRoom animation and Cliproom video editing.
15–21 s: Show productivity: a document, budget sheet, slide deck and calendar coming together.
21–25 s: Show files moving between rooms and the benefit of a self-hosted workspace.
25–30 s: Resolve to the RoomSuite arch, wordmark and a readable call to action: github.com/ElHombreAlex/RoomSuite.

Use restrained flame-orange accents, short readable captions, purposeful pointer and panel animations, and smooth motion. Show concrete examples instead of just a list of room names. The timings are a guide; maintain an intentional rhythm and leave enough time to read. Do not invent capabilities, prices, savings, benchmark figures, security guarantees, customer logos or testimonials. Label visual mockups as illustrative where they could be mistaken for the actual UI.

Create the substantive artwork, animation and edit with RoomSuite MCP, using MotionRoom and Cliproom. You may delegate to subagents and use suitable available models. Preserve the editable projects and assets. Use no paid external image or video generation. If you have original or appropriately licensed music/effects, you may add them and record their provenance; never reuse the reference soundtrack without permission. If no suitable cleared audio is available, deliver a silent cut and state that. MotionRoom's video export is silent; assemble audio in Cliproom if used.

DELIVERABLES AND REVIEW
- One finished 30-second (±0.25 s) 1280 × 720 video, targeting 30 fps. Prefer MP4/H.264 if supported; provide WebM if MP4 is unavailable and report the actual codec and frame rate. If audio is used, also provide a silent master.
- Editable MotionRoom and Cliproom projects or IDs, source assets, a short scene list and a contact sheet with frames covering every scene. Verify the exported video plays, is the requested duration and dimensions, shows the intended motion and readable text, and has audible audio if audio is claimed.
- A results report with output paths, sizes and SHA-256 checksums; room/tool actions; elapsed wall time; parent/subagent roles and models; attempted/successful/failed MCP calls; and cached input, uncached input, output tokens and API cost across all agents when supported by usage records. Include retries and orchestration. Mark missing totals incomplete or unavailable, distinguish billed from estimated costs, and list any paid services and audio provenance.
- State what was automatically checked and what needs independent human review. Report failures and unsupported codecs rather than claiming success. Do not publish or send the video.
```

Capture provider usage after the final response, including all subagents and model providers. Review the video and claims independently before promoting or publishing it.
