# Cliproom project packages

In Cliproom, save the timeline, open the project list and choose **Download package** next to the saved project. **Import package** creates a new project and new server media entries; existing projects and media are not overwritten. An import verifies all packaged media before publishing the new project. It preserves timeline properties and clip IDs while assigning new media IDs. The editor asks before replacing an unsaved open timeline.

Packages include every media item listed in the saved project, including project-library items that are not currently on the timeline. They are limited to 250 media files and 256 MiB total, with a 2 MiB editable project limit. They are uncompressed, so the server needs temporary disk space to prepare an export or to hold the upload and extracted media during import. Only one package is prepared at a time; a slow download does not hold the project/media catalog lock. Keep the original project and backups until the imported result has been checked. Browser codec support still governs playback and rendering.

The `.roomclip` version 1 file is a simple local archive: the ten ASCII bytes `ROOMCLIP1\n`, a four-byte unsigned big-endian manifest length, a UTF-8 JSON manifest, and each media file's raw bytes in manifest order. The manifest contains `format: "roomsuite.cliproom-package"`, `version: 1`, the source project ID and revision, the editable timeline state, and media records with original UUID, name, MIME type, size and SHA-256. The manifest is at most 3 MiB. Hashes detect accidental or intentional changes to media bytes; they do not establish who created a package. The importer rejects malformed manifests, unsupported references, missing or extra media, mismatched hashes and oversized packages. It does not execute package contents or use embedded filenames as filesystem paths.

Agents use `cliproom_export_package` with a project ID and current revision, then `cliproom_import_package` with a new UUIDv4 project ID. The caller-supplied ID lets an agent check whether an import succeeded if a response is lost. Standard Shared files upload/download tools can transfer a package between the agent workspace and Shared files.
